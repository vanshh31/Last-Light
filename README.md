# LAST LIGHT

### Survive the darkness. Adapt. Keep fighting.

**LAST LIGHT** is a 2D survival-action game prototype developed in Unity 6. Fight increasingly challenging waves of enemies, collect energy, unlock upgrades, and see how long you can survive.

---

## 🎮 Game Overview

| Detail | Description |
|---|---|
| Title | LAST LIGHT |
| Genre | 2D Survival / Action Roguelite |
| Engine | Unity 6 |
| Language | C# |
| Render Pipeline | Universal Render Pipeline (2D) |
| Platform | Windows / WebGL |

## ✨ Gameplay Features

- **Player Movement:** Navigate the arena using WASD controls.
- **Automatic Combat:** Automatically target and attack nearby enemies.
- **Enemy Waves:** Survive progressively challenging enemy waves.
- **Energy Collection:** Collect energy dropped by defeated enemies.
- **Upgrade System:** Spend collected energy to improve damage, fire rate, and attack range.
- **Health System:** Monitor player health and survive incoming attacks.
- **Daily Challenge:** Take on a challenge with predefined modifiers and objectives.
- **Pause System:** Pause gameplay and access the pause menu.

## 🕹️ Controls

| Input | Action |
|---|---|
| W / A / S / D | Move |
| Automatic | Targeting and combat |

## 🚀 Getting Started

To explore or run the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/vanshh31/Last-Light.git
   ```

2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Select the cloned `Last-Light` folder.
5. Open the project using a compatible Unity 6 installation.
